توسعه‌دهندهٔ جدید ابتدا معماری و جریان اجرا را بخواند، سپس برای پیاده‌سازی از راهنمای توسعه استفاده کند. گزارش بررسی مشخص می‌کند کدام بخش‌های Auth هنوز الگوی قابل کپی نیستند.

## Auth اکنون چه می‌کند؟

- ورودی موبایل یا ایمیل و انتخاب کاربر حقیقی/حقوقی را می‌گیرد.
- درخواست OTP، ارسال مجدد و تأیید OTP را انجام می‌دهد.
- DTO کاربر را در سرویس با مپر به مدل UI تبدیل می‌کند.
- توکن موقت OTP را در state هوک نگه می‌دارد.
- پس از تأیید، `access` و `refresh` را در `localStorage` ذخیره می‌کند.
- مرحلهٔ UI را به `LOGGED_IN` می‌برد و متن `Login Success` نمایش می‌دهد.

به‌روزرسانی ۲۰۲۶-۱۰-۱۸: ارسال Bearer و تمدید خودکار پس از 401 به کلاینت مشترک متصل است و خروج پنل کاربری refresh token را به `/api/auth/logout/` می‌فرستد، توکن‌ها و کش محلی را پاک می‌کند و به `/login` می‌رود. بازیابی پروفایل بعد از reload و کنترل دسترسی مسیرها همچنان تکمیل‌نشده‌اند.

## نقطهٔ ورود و پیش‌نیازها

- مسیر صفحه: `/login`؛ فایل [page.tsx](<../../../app/(auth)/login/page.tsx>) فقط `LoginPage` را رندر می‌کند.
- [layout احراز هویت](<../../../app/(auth)/layout.tsx>) فرزندان را داخل `ReactQueryProvider` قرار می‌دهد.
- HTTP از `@/shared/api` می‌آید؛ آدرس پایه از `NEXT_PUBLIC_API_URL` خوانده می‌شود. URL، توکن یا اطلاعات واقعی محیط را داخل مستند یا کد نمونه وارد نکنید.
- فرم شناسه از React Hook Form و Zod استفاده می‌کند. درخواست‌ها با TanStack Query و Axios اجرا می‌شوند.
- [Button](../../../components/ui/button.tsx) و [Input](../../../components/ui/input.tsx) اجزای مشترک UI هستند؛ فرم‌های فعلی Auth در چند محل input بومی دارند.

## وضعیت اعتبار مستندات

عبارت «اکنون» گزارش کد موجود است. عبارت «الگوی پیشنهادی» روش ساخت فیچر جدید است و به معنی اجرای آن در همهٔ فایل‌های فعلی نیست. موارد «نیازمند تأیید بک» از روی TypeScript یا نام endpoint اثبات نمی‌شوند.

در این بازبینی فقط مستندات اصلاح شده‌اند. نقص‌های کد، از جمله مپ نشدن `user_type`، در [گزارش بررسی](review.md) ثبت شده‌اند.

## نگهداری مستند

همراه تغییر endpoint، DTO، خروجی سرویس، state مراحل یا export عمومی، سند مرتبط را در همان تغییر به‌روز کنید. برای هر قابلیت جدید مسیر ورودی تا خروجی، حالت خطا و راه بررسی آن را بنویسید؛ رفتار برنامه‌ریزی‌شده را به‌عنوان رفتار موجود ثبت نکنید.
